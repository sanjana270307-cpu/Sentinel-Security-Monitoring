# SENTINEL – Security Operations and Threat Monitoring Platform

A lightweight, desktop-based cybersecurity application designed to monitor authentication activities, identify suspicious login behaviour, and generate security alerts.
Sentinel is developed using Python, CustomTkinter, and MySQL. It follows a rule-based approach to authentication monitoring and is inspired by the core concepts of Security Information and Event Management (SIEM) systems.

## Features

- **Secure Authentication:** User registration and login with bcrypt password hashing.
- **Login Activity Monitoring:** Records successful and failed login attempts.
- **Account Lockout:** Temporarily locks an account after five consecutive failed password attempts.
- **Brute-Force Detection:** Identifies repeated failed login attempts within a defined time window.
- **Suspicious Login Detection:** Flags successful logins preceded by multiple failed attempts.
- **Security Alerts:** Generates alerts with severity levels for detected suspicious activity.
- **Dashboard:** Displays security statistics and recent activity.
- **Audit Logs:** Maintains records of important application activities.
- **User Management:** Provides administrative user management functionality.
- **Role-Based Interface:** Provides separate Analyst and Admin interfaces.

## Database Design

Sentinel uses MySQL with four main tables:

1. **users** – Stores user accounts, password hashes, roles, and account-lockout information.
2. **login_events** – Records successful and failed login attempts.
3. **security_alerts** – Stores alerts generated by the detection engine.
4. **audit_logs** – Maintains records of important application activities.

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd Sentinel
```

### 2. Create a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file in the project root using `.env.example` as a reference.

Add your own MySQL configuration:

```env
DB_HOST=localhost
DB_USER=your_mysql_username
DB_PASSWORD=your_mysql_password
DB_NAME=your_database_name
```

### 5. Set up the MySQL database

Create the database and required tables using the SQL schema provided with the project.

Make sure the database name matches the `DB_NAME` value in your `.env` file.

### 6. Run the application

```bash
python3 main.py
```

## Detection Rules

Sentinel currently implements two authentication-focused detection rules:

- **Brute-Force Detection:** Detects five or more failed login attempts within five minutes.
- **Suspicious Login Detection:** Identifies a successful login preceded by five or more failed attempts within ten minutes.

These rules generate alerts for further investigation. An alert indicates suspicious activity and does not by itself prove that an account has been compromised.

## Security Considerations

- Passwords are stored using bcrypt hashes rather than plaintext.
- Database credentials are maintained in environment variables.
- Parameterized SQL queries are used for database operations.
- Sensitive configuration files are excluded through `.gitignore`.

## Project Scope

Sentinel is a lightweight authentication monitoring and threat detection application inspired by SIEM concepts. Its current scope focuses on login activity, account security, rule-based detection, and audit monitoring. It is not a full enterprise SIEM solution.
